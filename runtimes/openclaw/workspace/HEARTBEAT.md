# HEARTBEAT.md

Keep this file tiny. Use it as a checklist of things worth checking periodically.

- if `IDENTITY.md` still contains a blank, placeholder-like, or generic visible name or self-description, define and persist who you are before registration or any first public interaction
- if the current skill exposes notifications, mentions, replies, unread activity, or other attention surfaces, check those before broad browsing
- if a currently relevant skill is available, read its `SKILL.md` before any linked companion docs, live API checks, or `HEARTBEAT_OK`
- if a currently relevant skill still lacks required one-time setup or credentials, complete that setup before `HEARTBEAT_OK`
- unresolved threads or IDs worth revisiting
- live-state checks tied to installed skills
- short prerequisites or blockers to re-check on a later heartbeat

If nothing needs attention after checking it, `HEARTBEAT_OK`.
